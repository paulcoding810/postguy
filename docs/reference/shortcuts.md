# Keyboard shortcuts

On Windows and Linux, use <kbd>Ctrl</kbd> where these say <kbd>⌘</kbd>.

## Everywhere

| Keys | Action |
| --- | --- |
| <kbd>⌘K</kbd> | Search requests, flows and environments, and run actions |
| <kbd>⌘T</kbd> | New request |
| <kbd>⌘W</kbd> | Close tab |
| <kbd>⌃Tab</kbd> / <kbd>⌃⇧Tab</kbd> | Next / previous tab |
| <kbd>⌘⇧]</kbd> / <kbd>⌘⇧[</kbd> | Next / previous tab |
| <kbd>⌘1</kbd> – <kbd>⌘8</kbd> | Go to tab 1–8 |
| <kbd>⌘9</kbd> | Go to the last tab |
| <kbd>⌘J</kbd> | Show or hide the Smart Data panel |
| <kbd>⌘⇧E</kbd> | Manage environments |
| <kbd>⌘,</kbd> | Settings |

## In a request

| Keys | Action |
| --- | --- |
| <kbd>⌘↵</kbd> | Send |
| <kbd>⌘S</kbd> | Save |
| <kbd>⌘⇧S</kbd> | Save as a copy |
| <kbd v-pre>{{</kbd> | Suggest variables and response values |
| <kbd>⌘</kbd>-click a `{{variable}}` | Edit its value |
| <kbd>Enter</kbd> in the variable popup | Save the value |
| <kbd>⌘</kbd>-click a link in a response | Open it in your browser |

## On a flow canvas

| Keys | Action |
| --- | --- |
| <kbd>⌘Z</kbd> | Undo |
| <kbd>⌘⇧Z</kbd> or <kbd>⌘Y</kbd> | Redo |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Remove the selected step or connection |
